# Website Untuk Pacar ❤️

Website romantis sederhana, responsif, dan bisa langsung dipasang di GitHub Pages.

## Struktur
- `index.html` — isi website
- `style.css` — tampilan
- `script.js` — interaksi dan animasi
- `music/` — opsional, untuk lagu

## Personalisasi
Buka `script.js`, lalu ubah:
```js
const name = "Sayang";
```

Kamu juga bisa mengganti cerita, alasan, surat, dan pertanyaan langsung di `index.html`.

## GitHub Pages
1. Buat repository baru di GitHub, misalnya `website-pacar`.
2. Upload semua file.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan. GitHub akan memberikan alamat website Pages.

## Catatan musik
Browser biasanya memblokir autoplay audio. Karena itu tombol musik harus ditekan oleh pengunjung.
